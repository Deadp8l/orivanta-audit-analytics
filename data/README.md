# Synthetic data

All data in this repository is synthetic and relates to the fictional Orivanta company. No real customers, employees, employers, clients, or transactions are represented.

## `synthetic_source/`

Contains the source tables used by the Python and SQL analytics, the data dictionary, generation metadata, and a SQLite database for SQL reproduction.

## `benchmark/`

Contains a synthetic answer key and summarized benchmark results used to evaluate inclusion and exclusion behavior. The benchmark constrains effectiveness claims; it is not evidence of real-world detection performance.

The analytical population contains deliberately planted control conditions for portfolio testing. Results should not be generalized to a production environment.

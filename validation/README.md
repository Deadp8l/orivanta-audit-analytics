# Validation evidence

This folder preserves compact evidence of the test runs cited publicly:

- `repository_pytest_output.txt` — captured original repository test run: 5 passed.
- `69_reference_scenarios_pytest_output.txt` — enhanced boundary scenarios across nine priority tests: 69 passed.

The selected result files in [`../results/`](../results/) provide the headline metrics, reconciliation population, and record-level SQL/Python comparison used in the case study.

Passing tests and matching SQL/Python outputs support implementation consistency. They do not prove that every business criterion is complete or that every flagged record is a true adverse event.

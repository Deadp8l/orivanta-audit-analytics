# Financial measure definitions

The financial measures answer different questions and must not be added together.

## Population measures

### Gross overlapping flagged value — $60,962.90

The sum of test-result activity before record-level overlap removal. A transaction can appear in more than one test. This is analytical activity, not confirmed loss.

### Record-level deduplicated flagged value — $34,581.18

The largest applicable flagged amount retained for each record using the documented key hierarchy. This reduces overlap but remains a flagged population measure.

## Conclusion measures

### Direct measurable differences — $14,756.86

Calculated differences supported by documented arithmetic rules. For example, only a credit amount above the linked eligible charge is treated as measurable. These differences still require management validation and are not automatically financial loss.

### Investigative transaction value — $23,139.04

The value of records requiring contextual review. This measure describes an investigative population, not a confirmed adverse outcome.

### Confirmed financial loss — not established

The supplied evidence does not establish final loss, recovery status, or management disposition. Confirming loss would require transaction-level validation, supporting documentation, entitlement analysis, disposition evidence, and exclusion of reversals, corrections, recoveries, and other legitimate explanations.

## Reconciliation measures

The reconciliation population contains 20 account-level exceptions, $1,575 in gross absolute difference, and a $175 signed net difference. The smaller net value does not eliminate offsetting account-level exceptions.
